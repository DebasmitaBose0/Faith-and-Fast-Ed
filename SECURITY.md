# Security Policy

## Supported Versions

Only the latest version of the Faith & Fast application is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it via the following steps:

1. **Do not** disclose the vulnerability publicly in issues or pull requests.
2. Send an email to the security team at `security@faith-and-fast.example.com` with a detailed description, reproduction steps, and potential impact.
3. We will acknowledge your report within 48 hours and provide a timeline for resolution.
4. Once resolved, we will publish an advisory and credit you for the discovery.
